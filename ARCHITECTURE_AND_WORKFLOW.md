# Architecture and workflow

Operator request -> fixed command allowlist -> real deterministic fixture processes -> native WorkLedger -> Meterless read projection -> Evaluator rejection/repair -> STOP/readback -> SVG/HTML and SHA256 seal.

The console observes actual argv, PIDs, stdout/stderr, role results, state transitions and file diffs. It does not become a second authoritative ledger. Every installation Moot node begins UNKNOWN and changes only after local observation. Optional references are pinned static references and never block the base three-case path.

The Public tree includes the minimum dependency closure of the existing native WorkLedger algorithms. General procedure execution, private Git transport and ingest tooling, owner gateways, host brokers and authentication are excluded. The owner profile retains individually authorized tools on the owner-controlled workstation. Neither profile enables unbounded autonomy by default.
