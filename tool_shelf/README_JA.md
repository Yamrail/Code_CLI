# 工具棚と引渡し区分

パッケージ直下で `python tool_shelf/shelf_tools.py list` または `python tool_shelf/shelf_tools.py verify` を実行します。Python標準ライブラリだけを使うオフラインの目録・原byte照合であり、回収工具をimport・実行しません。欠落工具の機能を代替したとは主張しません。

R005で回収された289ソース系統と32の重複する名称別能力を、従前の成熟度のまま収録しています。これは設置済み工具数ではありません。今回作成した目録・照合アダプタは別区分です。PASS・FAIL・未検収・未mergeによる一律除外は行わず、source-only、design-only、UNKNOWNを保持します。

審査員向け `hackathon_judge` 候補には、出自・状態の整理済み目録と照合アダプタに加え、個別照査したR008既設OSINT描画器を置きます。R005の未照査回収物は入りません。R008の自作コードは `OWNER_RELEASE_PENDING`、Noto派生フォントは隣接するOFLライセンスを保持します。Private GitHub認証、構築者の原版ZIP、本人ホームの絶対パス、独占ソフトの複製に依存しません。Rootが別途組み込むネイティブ中核の実行範囲は、その実装と実行証憑を正とします。

`full_authorized_handoff` は構築側のPrivate領域へ別置きし、照査済みのYamRailネイティブソース、版・SHA256・取得元を保持します。第三者権利未確定、依存環境、秘密値候補、Private・正本の台帳実体、本人絶対パス依存はpayloadから除外し、系統別の理由と取得pinを残します。R005原版ZIPはどちらの配布profileにも含めません。

自作工具も `OWNER_RELEASE_PENDING` とし、OSSライセンスやHuman承認を捏造しません。指定協力者への引渡し範囲と所有者のrelease権限は別途必要です。未確定ライセンスを配布許可として扱わず、ソース移送から実行・外部通信・正本昇格の権限を推定しません。
