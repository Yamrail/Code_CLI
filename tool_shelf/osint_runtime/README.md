# Reused native OSINT rendering runtime

`adapters/osint_render.py` exposes `render_graph(case_path, out, graph_type='content')`, `make_report(case_path, out)` and `history_graph(snapshot_path, out)`. Output directories must be fresh. Root's CLI wraps these local tools in the existing native WorkLedger stage; these functions do not create another state machine or authenticate an OSINT server session.

The additional `workledger` and `security` graph types require an appropriate native projection/recon JSON document. Its exact original bytes become `sources/C1.txt` and `original_input.json`; a bounded derived MD document quotes declared JSON state/typed relations without reconstructing another ledger or promoting references into causation. Omitted fields are indexed and remain available in original JSON. JSON origin/currentness remains UNKNOWN unless separately established by the Host. These types use the same pinned MD/CAD/PNG/vector pipeline. An unrelated schema or ordinary content case is rejected with an explicit HOLD. Reports also accept these native JSON documents and label the MD as derived, with original JSON and derived MD SHA256 kept separate. Both `Report.md`/`Report.pdf` and lowercase `report.md`/`report.pdf` aliases are emitted byte-identically.

The content path calls the exact pinned `explanatory_graph.derive_structured_md`, `structured_md_renderer`, `silver_board_renderer` and existing `cad_display_station.render_svg` primitive engine. The history path calls `investigation_dependency_graph.dependency_graph`, retaining `PERSISTED_CONTEXT_REFERENCE` and `NOT_INFERRED` causation. `graph_png.render_png` launches its real restricted rendering subprocess; `graph_artifacts._png` checks those actual PNG bytes. `silver_export.vector_pdf` supplies the original A4 vector export, with an explicit 8mm margin. Original source modules are byte-identical to GitHub PR79 commit `9f3a5e61b72a0517f683d3e7ccd22a0904782fec`.

PR62 commit `907593e0d045cfc926943d186eb0aa19ad7c92bb` comparison code and order were remotely read as design/provenance references; its browser UI was not executed. `document_versions.py` and other server interfaces were read/pinned but are not an authenticated application-server integration. No cloud engine, canonical ledger instance, model, sponsor provider or external URL is invoked. The exact local Markdown and declared source classes remain visible. Rendering does not establish factual truth, source independence or Human authority.

The local presentation derivative changes bounded header captions to show owner, scope, frozen time, source ID/title/issuer index, and the non-causal legend. Source graph geometry and relations are preserved. SVG/PNG use a documented uniform A4 fit; PDF uses the native 8mm vector exporter. Both the unchanged native SVG and the final render master are retained. `graph_master.json` and receipts bind the adapter, original modules, exact input, source register, MD, output bytes and font. Glyph substitutions and source IDs missing from nodes produce a local HOLD.

Report output contains `original_report.md` (exact original UTF-8), `Report.md` (explicit derived brief/index), `Report.pdf`, exact source files, a source register, graph outputs and receipts. Existing `document_guard.inspect_document` runs locally; REVIEW findings are retained and never used as prose correctness certification or auto-edited away.

Use the case contract in `fixtures/osint_case.json`. Source IDs are `C1`, `C2`, etc. `body_sha256` is SHA256 of the exact UTF-8 `body_text`; these bytes are written to `sources/<id>.txt`. The sample sources are fictional `SYNTHETIC_FIXTURE`, not external original evidence. The native history fixture carries the unchanged native snapshot contract plus a declared `code_cli_case` fixture for visible metadata/source IDs. All digests are frozen; links are not created from timestamp order.

`requirements-local-render.txt` records actual resolved build versions. The interpreter and dependencies are separately installed OSS components; no Microsoft font, Office/AutoCAD binary or licensed host application is copied. The bundled static YamrailBoard font is an exact Noto Sans JP derivative under the SIL OFL 1.1; its license, original source lock and glyph metrics are adjacent. Native YamRail code and vendor source have no observed public redistribution license and remain `OWNER_RELEASE_PENDING`. Preparing this private candidate does not approve external disclosure.
