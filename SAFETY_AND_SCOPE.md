# Safety and scope

The intended operator is a professional white-hat investigator or equivalent
technical collaborator with documented rights over the selected target. No
personality or character score grants access authority.

Default scope is the packaged synthetic local fixture. Recon reads and hashes
files and performs static analysis. It does not execute target code, send
network requests, exploit a vulnerability, gather credentials or alter targets.
Persistent symlink, reparse, hardlink, ADS/path traversal and size violations
hold before admission where implemented. These checks are not a claim of an
adversarial filesystem sandbox.

Externally sourced cases need source IDs, issuer/title, location, original-byte
SHA256, observation and event/disclosure time where known, claim basis,
revision and explicit UNKNOWN/HOLD/hypothesis classifications. Generated
reports and diagrams are not original evidence. Reference edges do not imply
causation or geographic accuracy.

New network targets, paid calls or provider side effects require host scope and
bounded cost admission. An uncertain completion must not be automatically
retried. A local HOLD does not imply a global stop for unrelated work.

Tool inventory keeps failed, unfinished, design-only and unqualified prototypes.
Qualification maturity does not grant or deny copyright/license permission.
Unknown redistribution rights are separately recorded and the corresponding
source is excluded from judge export until resolved.

AutoCAD is a separate local desktop exception only when actual entitlement and
the trusted user broker are qualified. This package provides no server/cloud
AutoCAD route, APS/Design Automation route, license forwarding, unattended
remote-worker access, AutoLISP/script autoload or commercial binary bundle.
